# ascend-assets

Shared masthead files for the ASCEND dashboards in this organization: `ascend-mast.js` (loads `ascend-mast.css`, the logo and the stats script from this same folder), plus the favicon and wordmark. Pages include it as `/ascend-assets/ascend-mast.js`.

`ascend-updated.js` adds the "Last updated" button at the top right of the masthead, for example "Last updated Nov 22, 2026 · 3 files". Clicking it opens the dashboard's update log: its recent updates, each with the date, one line on what changed and the files in that update. `ascend-mast.js` loads it by itself; a page without the shared masthead includes `/ascend-assets/ascend-updated.js` once at the end of `<body>`. A page that knows when its data was last rebuilt can state that date instead (`window.ASCEND_UPDATED`, or `data-updated` on the script tag). Details are in the file's opening comment.

The log is one file per dashboard repo, `updates/data/<repo>.json`, written by `updates/build-updates.mjs` from the repo's history on GitHub: date, first line of the description and file names only. The Pages workflow rebuilds them every 30 minutes when the repository secret `DASHBOARD_READ_TOKEN` is set (a token that can read the organization's repos; Contents: read-only is enough). Without the secret the committed files are published as they are; refresh them by hand with `node updates/build-updates.mjs` (uses the `gh` login) and commit. A dashboard that is not served from `*.github.io` names its repo with `data-log="<repo>"` on the script tag.
